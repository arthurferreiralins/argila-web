# Argila+ — Site institucional

Site institucional da **Argila+**, ateliê de esculturas em argila de alto padrão.

## Estrutura

- `index.html` — homepage (hero, coleção "em breve", história, sobre, missão/visão/valores, contato)
- `manual-de-marca.html` — manual de identidade visual (logotipo, paleta, tipografia, regras de uso)
- `assets/` — logotipo oficial da marca (arquivo fonte: `Argila+.png`) e recortes derivados:
  - `logo-full.webp` — lockup completo (emblema + nome + slogan + selo)
  - `logo-emblem-wordmark.webp` — emblema + nome (sem slogan/selo)
  - `logo-emblem.webp` — emblema isolado (ícone/avatar)
  - `favicon.png` — ícone da aba do navegador

## Regra de identidade visual

O logotipo oficial é o arquivo fornecido pela marca. Não recriar, redesenhar ou substituir por
outra versão — apenas recortar/redimensionar mantendo a proporção original (ver `manual-de-marca.html`).

Nenhum produto, peça ou preço é exibido neste site enquanto a primeira coleção está em desenvolvimento.
